Detailed Description

The lsScene class must be used for any Scene.

The base node for any scene in vortxGE.

Holds an Event Manager that controls all nodes in this scene. e.g. To delete a scene object just create an Event and the Scene node will take care of it safely.

maxProxies - Make sure you set this high enough to cover all your ridged bodies (bullet physics) or bullet will crash.
