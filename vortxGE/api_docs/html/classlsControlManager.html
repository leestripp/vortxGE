Detailed Description

Manage other control objects including Composite and Viewer.

When building your pipeline add you controls in the right order.
Add a Composite Control first so it becomes the last item rendered.
Controls are added into the top of the list.

Parent class is vortxGE.
vortxGE calls the Update() and Render() functions.
Resize() sould only be called by the user if the GL context has changed e.g. A Window Resize..
