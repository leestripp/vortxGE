Detailed Description

Graphics Engine Core.

Create an instance of this class in your app. You call Init() once you have a working openGL context. Then in a loop, call Update() and Render().

Init sets up the following instances. lsOpenGL lsShaderManager : also passed to lsOpenGL as ref lsStats : also passed to lsOpenGL lsAssetManager : All lsControls have their own Asset Manager, this one is only used for global assets. lsControlManager : Viewer, Menus, Scene, Gameplay Controls

void vortxGE::Update ( double  delta)

Calls Update() on the base Control Manager. This does threaded Move and Optimise on scene nodes to build a draw list based on cull camera and passes. This updates all scene elements, matrix data, physics and animation.
